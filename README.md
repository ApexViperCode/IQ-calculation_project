## ⚡ About the Project

Welcome to the **Ultimate IQ Test**! This web application tests logic, mathematical patterns, visual puzzles, and problem-solving skills across **20 carefully curated questions**. 

Featuring a striking dark-mode aesthetic with fiery ember glows and neon effects, the app dynamically tracks user progress, calculates a normalized IQ score, and generates an exhaustive breakdown report with correct/incorrect tracking and step-by-step logical explanations!

---

##  Epic Features

*  **Blazing Neon Aesthetics:** Custom-designed dark theme with fiery background gradients and glowing UI components.
*  **20 Advanced IQ Challenges:** Diverse question types covering patterns, algebra, probability, word logic, and spatial reasoning.
*  **Smart State Management (`LocalStorage`):** Seamless multi-page navigation that securely saves user answers across all 20 question pages.
*  **Instant IQ Calculation & Analysis:** Automatically computes the final IQ score and categorizes performance (from Average to Genius).
*  **Detailed Error Review Report:** Displays a final summary showing user answers, correct answers, and thorough explanations for every question so users can learn from their mistakes.
